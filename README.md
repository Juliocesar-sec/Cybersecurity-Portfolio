###  About This Repository

This repository documents my structured cybersecurity learning journey through hands-on labs, practical exercises, networking concepts, and offensive/defensive security tooling.

The objective of this portfolio is to build real-world cybersecurity skills while preparing for industry-recognized certifications and future roles in:

* SOC Analysis
* Security Operations
* Penetration Testing
* Blue Team Operations
* Infrastructure Security

This repository serves as both:

* A personal knowledge base
* A practical cybersecurity portfolio
* A progress tracker for labs, tools, and certifications
