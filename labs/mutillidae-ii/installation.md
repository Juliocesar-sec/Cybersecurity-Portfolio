# Mutillidae II Setup

## Objective
Install and configure Mutillidae II locally for web app pentesting.

## Steps
1. Download Mutillidae II from OWASP or GitHub  
2. Set up XAMPP / LAMP / Docker  
3. Deploy in web server root  
4. Open `http://localhost/mutillidae/` in browser

## Notes
- Mutillidae II is intentionally vulnerable  
- Always use controlled lab environments
