# SQL Injection Lab

## Objective
Practice SQL injection attacks safely.

## Steps
1. Identify input fields (login/search)  
2. Test payloads like `' OR 1=1 --`  
3. Observe database behavior  
4. Document vulnerable fields and mitigations

## Lessons Learned
- SQLi allows attackers to manipulate backend databases  
- Parameterized queries prevent SQLi  
- Safe lab practice is critical
