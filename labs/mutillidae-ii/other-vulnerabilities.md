# Other Vulnerabilities Lab

## Objective
Explore additional vulnerabilities in Mutillidae II.

## Topics
- **CSRF**: Cross-Site Request Forgery, exploits authenticated user sessions  
- **File Upload**: Uploading malicious scripts to gain server access  
- **Command Injection**: Execute system commands via vulnerable input  
- **Security Misconfigurations**: Weak permissions, debug pages

## Steps
1. Identify vulnerable input points  
2. Test each vulnerability in lab environment  
3. Document steps, findings, and mitigations  

## Lessons Learned
- Understanding multiple vulnerabilities improves penetration testing proficiency  
- Safe lab environments allow repeated practice  
- Documentation is key for portfolio and reports
