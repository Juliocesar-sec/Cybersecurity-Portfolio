# Cross-Site Scripting (XSS) Lab

## Objective
Test for reflected and stored XSS vulnerabilities.

## Steps
1. Locate input fields rendered in browser  
2. Inject scripts like `<script>alert('XSS')</script>`  
3. Observe execution and affected pages  
4. Document findings

## Lessons Learned
- XSS can steal cookies or manipulate web content  
- Input validation and encoding prevent XSS  
- Safe lab practice reinforces PenTest+ skills
