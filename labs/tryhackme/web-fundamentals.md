# TryHackMe Lab: Web Fundamentals

## Objective
Learn basic web application vulnerabilities.

## Steps
1. Explore web pages for input fields  
2. Test common web vulnerabilities:
   - SQL Injection  
   - XSS  
3. Document vulnerable endpoints and payloads

## Lessons Learned
- Web applications are common attack vectors  
- Understanding request/response helps identify vulnerabilities  
- Safe lab environments like TryHackMe are essential
