# Cryptography Basics

## Key Concepts
- **Encryption**: converting data to unreadable format using a key
- **Decryption**: converting encrypted data back to readable format
- **Symmetric Encryption**: same key for encrypt/decrypt (AES)
- **Asymmetric Encryption**: public/private keys (RSA)
- **Hashing**: one-way transformation, cannot reverse (SHA-256)

## Common Uses
- SSL/TLS → encrypt web traffic
- VPNs → secure remote connections
- Password storage → hashed + salted

## Notes
Cryptography protects confidentiality and integrity. Understanding algorithms and use cases is essential for Security+.
