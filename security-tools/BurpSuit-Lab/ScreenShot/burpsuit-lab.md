# Burp Suite Lab

## Objective
Perform web application security testing.

## Steps
1. Configure browser proxy with Burp Suite  
2. Intercept HTTP requests  
3. Test for common vulnerabilities:
   - SQL Injection
   - Cross-Site Scripting (XSS)  
4. Document findings

## Notes
Burp Suite is essential for PenTest+ to test web application security.
