
# Wireshark Packet Analysis Lab

## Objective
Analyze network traffic to detect suspicious activity.

## Steps
1. Capture network traffic using Wireshark  
2. Filter HTTP and DNS requests  
3. Identify anomalies such as repeated failed logins

## Observations
- Detected multiple failed SSH login attempts  
- Identified DNS requests to unknown domains

## Notes
Wireshark helps in understanding normal vs malicious network behavior.
